# speech.cpp サーバー

アプリは音声合成（Irodori-TTS）・文字起こし・Voice Clone を、別に起動した speech.cpp のサーバー（`speech serve`）に HTTP で頼みます。サーバーはアプリと一緒には起動しないので、声で話す前に起動しておきます。

## 起動

[speech.cpp のリリース](https://github.com/nyosegawa/speech.cpp/releases) から OS に合った版を取得し、モデルを渡さずに起動します。

```powershell
speech serve --open
```

- `--open` はモデル無しで起動するために必要で、ブラウザで speech.cpp のページも開きます。
- 待ち受けるのは `http://127.0.0.1:8080` です。ポートを変えたとき（`--port`）や別の PC で動かすときは、`apps/server/.env` の `SPEECH_URL` を合わせます。

## モデル

音声合成のモデルはキャラクターの声の画面で、文字起こしのモデルは「設定 → モデル」の Speech To Text で選ぶと、サーバーがモデルを Hugging Face からダウンロードして読み込みます（`POST /speech/load`）。サーバーは音声合成と文字起こしのモデルをそれぞれ1つしか持てないので、キャラクターが話す前・文字起こしの前に、使うモデルでなければ読み込み直します（ダウンロード済みのモデルだけ）。文字起こしのモデルを選んでいないときは、サーバーが読み込んでいるモデルを使います。

- 音声合成で選べるのは、カタログ（`/speech/models`）にある Irodori-TTS のモデル（名前が `irodori-tts` で始まるもの）です。名前が `-mf` で終わる MeanFlow 版は、`--steps` を付けなければアプリが 12 ステップで生成します。
- 文字起こしで選べるのは、サーバーのカタログ（`/speech/models`）にある文字起こしのモデルのうち、言語に日本語を含むものです。speech.cpp を更新してカタログにモデルが増えると、選べるモデルも増えます。
- モデルの保存先は speech.cpp のモデルフォルダ（Windows では `%LOCALAPPDATA%\speech.cpp\models`）です。サーバーを起動するときに環境変数 `SPEECH_MODEL_DIR` を設定すると変えられます。
- ダウンロードを中止しても、次に選んだときに続きから再開します。
- 読み込んだモデルは、同じ種類の別のモデルに入れ替えるか、サーバーを止めるまで読み込まれたままです。speech.cpp にはモデルを外す機能がありません。
- 起動時にモデルを渡すこともできます（`speech serve irodori-tts parakeet-tdt_ctc-0.6b-ja`）。カタログの名前を渡すと、初めて使うときにサーバーがダウンロードします。

## 注意

- モデルの選択と、Voice Clone の声の追加（`/speech/voices`）は、サーバーが 127.0.0.1・`::1`・`localhost` で待ち受けているときだけ使えます。`--host` で別のアドレスを待ち受けると使えません（別の PC のサーバーは SSH のポート転送でつなぎます）。
- Voice Clone の声は、初めて使うときにボイスファイル（キャラクターの参照音声をつないだ WAV、または `.voice.gguf`）をサーバーへ送って加えます。サーバーを起動し直すと加えた声は消えますが、アプリが次に使うときに加え直します。
- サーバーは1つのモデルに1つずつリクエストを処理します。アプリが合成を止めるとリクエストを切るので、サーバー側の合成も止まります。
