# Discord のボイスチャンネルで話す

キャラクターが Discord の bot としてボイスチャンネルに参加し、そこにいる人と話します。bot はこの PC から Discord に接続するので、公開サーバーやポート開放は要りません。

## 準備

1. [Discord Developer Portal](https://discord.com/developers/applications) で「New Application」を作る。
2. 「Bot」で「Reset Token」を押し、表示されたトークンをコピーする（特権 Intent はどれも不要）。
3. アプリの「設定 → Discord」でトークンを貼り付け、「bot を動かす」をオンにし、話すキャラクターを選ぶ。
4. ログインできたら「サーバーに追加」から bot をサーバーに招待する（権限は「チャンネルを見る・接続・発言」）。

## 使い方

- ボイスチャンネルに入った状態で `/join` を打つと、キャラクターがそのチャンネルに参加します。
- `/leave` で退出します。チャンネルに誰もいなくなったときも退出します。
- 参加できるのは一度に 1 チャンネルです。

## しくみ

- 話した内容は、人ごとに無音（既定 800 ミリ秒）で区切って「モデル」の設定の聞き取り（speech.cpp / ElevenLabs）で文字にし、アプリのそのキャラクターとの会話に 1 ターンとして送ります。会話の履歴と記憶はアプリと共通です。
- 雑音を言葉として聞き取ることがあるため、句読点・記号・空白を除いて 5 文字未満の発言には答えません。
- 2 人以上いるときは、発言の頭に Discord の表示名を付けて送ります。
- 返答は一言か短い一文にするよう、ボイスチャンネルでの会話のときだけ指示を足します。
- 返答は文ごとに読み上げ（Irodori-TTS / ElevenLabs）で合成でき次第、チャンネルで再生します。「返答のしかた」で読み上げがオフだと喋りません。
- 発言を聞き取ってから返答を喋り終えるまでは、誰が話しても聞き取りません（途中で話しかけても止まらず、その発言には答えません）。
- 音声の受信は Opus を opusscript でデコードし、送信は 48 kHz の PCM を同じく opusscript でエンコードします。ffmpeg は使いません。
