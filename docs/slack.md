# Slack で話す

キャラクターが Slack の bot として、ダイレクトメッセージやチャンネルでの呼びかけにテキストで返事をします。Socket Mode を使い、bot はこの PC から Slack に接続するので、公開サーバーやポート開放は要りません。Slack の bot は通話（ハドル）に参加できないため、声では話しません。

## 準備

1. アプリの「設定 → メッセージ → Slack → 設定のしかた」で「コピー」を押し、マニフェストをコピーする。
2. [Slack API](https://api.slack.com/apps?new_app=1) で「From a manifest」を選び、ワークスペースを選んでマニフェストを貼り付け、アプリを作る。
3. 「Install App」でワークスペースにインストールし、「Bot User OAuth Token」（`xoxb-`）をコピーして、アプリの「Bot Token」に貼り付ける。
4. 「Basic Information → App-Level Tokens」で `connections:write` を付けたトークン（`xapp-`）を作り、アプリの「App-Level Token」に貼り付ける。
5. 「Slack に接続する」をオンにし、話すキャラクターを選ぶ。

トークンは環境変数 `SLACK_BOT_TOKEN`・`SLACK_APP_TOKEN` でも渡せます（アプリで入力したものが優先です）。

マニフェストで付ける権限は `app_mentions:read`・`chat:write`・`im:history`・`reactions:write`・`users:read`、受け取るイベントは `app_mention`・`message.im` です。

## 使い方

- bot にダイレクトメッセージを送ると、そこに返事をします。
- チャンネルでは `@` で bot を呼ぶと、そのメッセージのスレッドに返事をします。チャンネルに bot を招待しておく必要があります。
- 考えている間は、送ったメッセージに 👀 のリアクションが付きます。

## しくみ

- 届いたメッセージは、アプリのそのキャラクターとの会話に、文字で打ったのと同じ 1 ターンとして送ります。会話の履歴と記憶はアプリと共通です。
- チャンネルからのメッセージは、頭に Slack の表示名を付けて送ります。
- メッセージは届いた順に 1 つずつ答えます。アプリで返答中のときは最大 2 分待ち、それでも空かなければ、あとで話しかけるよう返します。
- 返事は読み上げず、返答が終わってからまとめて投稿します。編集・削除や bot のメッセージには答えません。
